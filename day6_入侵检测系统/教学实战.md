## 一、项目概述

基于 Scapy 的轻量级**网络入侵检测系统**，具备 8 种攻击检测引擎、滑动窗口告警机制、告警去重、JSON 日志输出。配套攻击模拟测试工具，可独立验证每种检测能力。

### 架构总览

```
网络流量（Scapy sniff）
         │
         ▼
  ┌──────────────────┐
  │  process_packet() │  ← 每个包经过 8 个检测器
  │                   │
  │  ┌─────────────┐ │
  │  │ SYN 扫描检测  │ │  >=15 端口/10秒
  │  │ ARP 欺骗检测  │ │  IP-MAC 不一致
  │  │ DNS 隧道检测  │ │  子域名>50字符 或 >50查询/分钟
  │  │ SYN 洪泛检测  │ │  >=200 SYN/5秒
  │  │ ICMP 洪泛检测 │ │  >=100 ICMP/5秒
  │  │ SSH 暴破检测  │ │  >=10 连接/60秒
  │  │ 可疑载荷检测  │ │  SQL注入/XSS/命令注入关键词
  │  │ Telnet 检测   │ │  端口23流量
  │  └─────────────┘ │
  └────────┬─────────┘
           │
     ┌─────▼─────┐
     │  告警输出   │ → 终端彩色输出 + JSON 日志文件
     └───────────┘
```

## 三、8 大检测引擎详解

### 3.1 SYN 端口扫描检测

```
检测原理：
  攻击者在短时间内对大量端口发送 SYN 包（半开扫描）
  
判定条件：
  同一源 IP → 目标 IP，在 10 秒内访问 >= 15 个不同端口
  
滑动窗口实现：
  ┌──────────────────────────────────────┐
  │  deque 存储 (timestamp, dst_port)     │
  │                                      │
  │  (t1, 80) (t2, 443) (t3, 22) ...    │
  │                                      │
  │  每次新包进来：                        │
  │  1. 移除窗口外（>10秒）的旧记录        │
  │  2. 检查去重后的端口数 >= 15           │
  │  3. 如果满足 → 触发告警               │
  └──────────────────────────────────────┘

教学重点 — 滑动窗口算法：
```python
from collections import deque
import time

class ScanDetector:
    def __init__(self, window=10, threshold=15):
        self.window = window        # 时间窗口（秒）
        self.threshold = threshold  # 阈值（端口数）
        self.history = deque()      # (timestamp, port) 队列

    def check(self, port):
        now = time.time()
        # 步骤1：移除窗口外的旧数据
        while self.history and now - self.history[0][0] > self.window:
            self.history.popleft()
        # 步骤2：添加新记录
        self.history.append((now, port))
        # 步骤3：检查去重端口数
        unique_ports = set(p for _, p in self.history)
        if len(unique_ports) >= self.threshold:
            return True  # 触发告警
        return False
```

### 3.2 ARP 欺骗检测

```
检测原理：
  ARP 欺骗 = 攻击者伪造 ARP 应答，让流量经过攻击者的机器
  
判定条件：
  同一 IP 的 MAC 地址发生变化

实现方式：
  维护 IP → MAC 映射表
  收到 ARP Reply 时检查：
  ├── IP 未见过 → 记录（首次学习）
  └── IP 见过但 MAC 不同 → CRITICAL 告警！

特殊情况：
  网关 IP（x.x.x.1）的 MAC 会特别关注
```

### 3.3 DNS 隧道检测

```
检测原理：
  DNS 隧道 = 利用 DNS 查询传输数据（绕过防火墙）
  攻击者把数据编码在子域名中：dataencoded.evil.com

两种检测方式：
  1. 子域名长度异常：subdomain > 50 字符
     例: dGhpcyBpcyBhIHRlc3Q.evil.com  (base64 编码数据)
  
  2. 查询频率异常：同一 IP 60 秒内 > 50 次 DNS 查询
     正常用户不会这么频繁地查询 DNS
```

### 3.4 SYN 洪泛检测

```
检测原理：
  SYN 洪泛 = 大量伪造的 SYN 包耗尽服务器资源（DDoS 一种）

判定条件：
  同一目标 IP 在 5 秒内收到 >= 200 个 SYN 包

与端口扫描的区别：
  端口扫描 → 来自一个 IP，去往多个端口
  SYN 洪泛 → 可能来自多个 IP，去往一个目标
```

### 3.5 ICMP 洪泛检测

```
检测原理：
  ICMP 洪泛 = 大量 ping 请求消耗带宽

判定条件：
  同一目标 IP 在 5 秒内收到 >= 100 个 ICMP Echo Request
```

### 3.6 SSH 暴力破解检测

```
检测原理：
  暴力破解 = 反复尝试 SSH 密码

判定条件：
  同一源 IP 在 60 秒内发起 >= 10 个 SYN 连接到端口 22

注意：只检测连接尝试次数，不检查密码是否正确
     （IDS 在网络层看不到 SSH 应用层的认证结果）
```

### 3.7 可疑载荷检测

```
检测原理：
  检查数据包载荷中是否包含攻击特征字符串

检测规则：
  ├── SQL 注入关键词：
  │   union select, 1=1, ' OR ', drop table, --
  │
  ├── XSS 关键词：
  │   <script>, javascript:, onerror=, onerror =
  │
  └── 命令注入关键词：
      ; cat, ; ls, ; whoami, | /bin/sh
```

### 3.8 Telnet 检测

```
检测原理：
  Telnet 是明文协议（端口23），任何使用都是安全隐患

判定条件：
  任何目标端口 23 的 TCP 流量 → 发出 INFO 级别告警
```

## 四、⚡ 安全性教学重点

### 4.1 API Key 与凭证安全

#### 本项目特点：无外部依赖，无 API Key

```
IDS 设计的安全原则：
├── 纯网络层分析，不调用任何外部 API
├── 不存储任何用户密码或密钥
├── 告警日志只包含网络元数据（IP、端口、时间）
└── 不记录数据包载荷的完整内容

这是安全监控工具的最佳实践：
IDS/IPS 本身不应成为攻击面。
```

#### IDS 告警日志的安全存储

```python
# 告警输出到 JSON 文件，包含以下字段：
{
    "timestamp": "2026-05-23T14:30:00",
    "rule": "SYN Port Scan",
    "severity": "HIGH",
    "src_ip": "192.168.1.100",
    "dst_ip": "192.168.1.1",
    "details": "15 unique ports in 10s"
}

# 安全要点：
# 1. 日志文件权限应设为 600（仅 root 可读）
# 2. 日志应定期轮转和归档
# 3. 敏感网络拓扑信息不应出现在日志中
# 4. 日志传输应加密（如果发送到集中日志系统）
```

### 4.2 告警去重机制

```python
# 问题：如果攻击持续进行，每个包都会触发告警 → 告警风暴
# 解决：同一规则在窗口期内只告警一次

def _fire_alert(self, rule_name, severity, src_ip, dst_ip, details):
    # 告警去重：同一条规则在同一窗口内只触发一次
    key = f"{rule_name}:{src_ip}:{dst_ip}"
    if key in self._recent_alerts:
        if time.time() - self._recent_alerts[key] < self.window:
            return  # 跳过重复告警

    self._recent_alerts[key] = time.time()
    # 输出告警...

# 教学意义：告警去重是所有 IDS/IPS 的核心需求
# 没有去重 → 告警洪水 → 安全人员疲劳 → 真正的攻击被淹没
```

### 4.3 规则引擎设计

```python
# 规则用数据类定义，与检测逻辑分离
@dataclass
class Rule:
    name: str           # 规则名称
    category: str       # 分类（scan/flood/intrusion）
    severity: str       # 严重等级（CRITICAL/HIGH/MEDIUM/INFO）
    threshold: int      # 触发阈值
    window: int         # 时间窗口（秒）

# 好处：
# 1. 规则可以外部配置（JSON/YAML 文件）
# 2. 不修改代码就能调整阈值
# 3. 可以按类别启停规则
```

## 五、代码架构教学

### 5.1 滑动窗口模式（Sliding Window）

```
这是本项目最核心的算法模式：

时间线：─────────────────────────────────────→
        t=0        t=5        t=10       t=15

窗口（window=10秒）：
        [=========]
                   [=========]
                            [=========]

每来一个事件：
1. 窗口右边界 = 当前时间
2. 窗口左边界 = 当前时间 - window
3. 移除左边界之前的旧事件
4. 统计窗口内的事件数
5. 超过阈值 → 告警

应用场景：
├── 端口扫描：10秒内 >15 个不同端口
├── SYN 洪泛：5秒内 >200 个 SYN 包
├── ICMP 洪泛：5秒内 >100 个 ICMP 包
└── SSH 暴破：60秒内 >10 个连接尝试
```

### 5.2 数据包处理管道

```python
def process_packet(self, packet):
    """每个抓到的包都经过这个函数"""
    # 按协议类型分发到不同检测器
    if packet.haslayer(TCP):
        self._check_syn_scan(packet)     # SYN 端口扫描
        self._check_syn_flood(packet)    # SYN 洪泛
        self._check_ssh_brute(packet)    # SSH 暴力破解
        self._check_telnet(packet)       # Telnet 检测
        self._check_payload(packet)      # 可疑载荷

    if packet.haslayer(ARP):
        self._check_arp_spoof(packet)    # ARP 欺骗

    if packet.haslayer(DNS):
        self._check_dns_tunnel(packet)   # DNS 隧道

    if packet.haslayer(ICMP):
        self._check_icmp_flood(packet)   # ICMP 洪泛
```

## 七、常见问题

| 问题 | 解决方案 |
|------|---------|
| `PermissionError` | 必须用 `sudo` 运行，抓包需要 root 权限 |
| `Scapy not found` | `pip install scapy` |
| 没有抓到任何包 | 检查网卡名称：`ip link show` 或 `ifconfig` |
| Windows 上报错 | 需要安装 Npcap：https://npcap.com/ |
| WSL 中无法抓包 | WSL 默认没有原生网络栈，推荐用虚拟机 |
| 告警太多 | 调整阈值参数，或只启用部分规则 |
