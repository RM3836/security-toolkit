## 四、⚡ 安全性教学重点

### 4.1 API Key 与凭证安全

#### 本项目的凭证处理

```
✅ 好的设计：无硬编码 API Key
  本项目不使用任何外部 API，所有检测逻辑自实现。

✅ 好的设计：SSH 凭证由用户输入
  SSH 管理模块的密码在运行时由用户输入，不存储在代码中。

⚠️ 需要注意：运行时安全
  SSH 密码在内存中以明文存在（Python 字符串）。
  程序退出后内存会被回收，但在运行期间有被 dump 的风险。
```

#### 安全编码示例

```python
# ❌ 错误：把 SSH 密码写在代码里
ssh.connect('192.168.1.1', username='root', password='MyP@ssw0rd')

# ✅ 正确：运行时由用户输入
import getpass
password = getpass.getpass("请输入 SSH 密码: ")
ssh.connect(host, username=username, password=password)

# ✅ 更好：使用 SSH 密钥认证
ssh.connect(host, username=username, key_filename='/path/to/private_key')

# ✅ 最好：使用 ssh-agent 代理
ssh.connect(host, username=username)  # 自动从 ssh-agent 获取密钥
```

### 4.2 SSL 证书验证

```python
# 本项目中的安全隐患：
requests.get(url, verify=False)  # 禁用了 SSL 证书验证！

# 为什么危险：
# verify=False 意味着接受任何证书，包括：
# - 自签名证书
# - 过期证书
# - 被中间人替换的证书
# 攻击者可以拦截 HTTPS 流量而不被发现

# 正确做法（生产环境）：
requests.get(url, verify=True)  # 默认值，验证证书

# 正确做法（测试环境，自签名证书）：
requests.get(url, verify='/path/to/ca-bundle.crt')

# 为什么安全工具中 verify=False 可以接受：
# 1. 安全扫描器需要扫描各种目标，包括配置错误的 HTTPS
# 2. 扫描器本身就是"探测"性质，不涉及敏感数据传输
# 3. 但应在文档中明确说明这是有意为之
```

### 4.3 SSH 主机密钥验证

```python
# 本项目中的安全隐患：
ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())

# 为什么危险：
# AutoAddPolicy 自动接受任何主机密钥，包括：
# - 首次连接的主机（正常）
# - 主机密钥发生变化的主机（可能是中间人攻击！）

# 正确做法（生产环境）：
from paramiko import RejectPolicy, WarningPolicy
ssh.set_missing_host_key_policy(RejectPolicy())  # 拒绝未知主机

# 或者预先加载已知主机密钥：
ssh.load_system_host_keys()
ssh.load_host_keys('/path/to/known_hosts')

# 为什么安全工具中 AutoAddPolicy 可以接受：
# 1. 安全评估工具需要连接各种未知主机
# 2. 工具的目的是检测对方的安全性，不是建立信任关系
# 3. 但应在报告中标注"主机密钥未经验证"
```

### 5.1 插件式模块设计（Strategy Pattern）

```python
# 每个安全模块都是独立的类，遵循统一接口：

    def run(self, target):
        """返回扫描结果字典"""
        ...

class WebScanner:
    def run(self, target):
        """返回扫描结果字典"""
        ...

class SecurityReport:
    def add_result(self, module_name, result):
        """聚合各模块结果"""

# 主程序通过菜单或 --auto 调度模块

# 1. 定义一个新类，实现 .run() 方法
# 2. 在菜单中添加一个选项
# 3. 在报告中添加结果收集
```

### 5.3 安全评分算法

```python
# 评分从 100 分开始，按发现扣分

score = 100

for finding in all_findings:
    if finding['severity'] == 'CRITICAL':
        score -= 20    # 严重发现扣 20 分
    elif finding['severity'] == 'HIGH':
        score -= 10    # 高危发现扣 10 分
    elif finding['severity'] == 'MEDIUM':
        score -= 5     # 中危发现扣 5 分
    elif finding['severity'] == 'LOW':
        score -= 2     # 低危发现扣 2 分

# 保底 0 分
score = max(0, score)

# 字母等级：
# A: 90-100  (优秀)
# B: 70-89   (良好)
# C: 50-69   (中等)
# D: 30-49   (差)
# F: 0-29    (危险)
```

### 5.4 一键评估的自动化调度

```python
# --auto 模式的调度逻辑：

def auto_assess(target):
    # 1. 先跑端口扫描
    port_result = PortScanner().run(target)
    open_ports = port_result['open_ports']

    # 2. 对发现的 HTTP/HTTPS 端口自动跑 Web 扫描
```

## 七、常见问题

| 问题 | 解决方案 |
|------|---------|
| `ModuleNotFoundError: scapy` | `pip install scapy`（IDS 和 SYN 扫描需要） |
| `ModuleNotFoundError: paramiko` | `pip install paramiko`（SSH 管理需要） |
| 一键评估只跑了端口扫描 | Web 扫描需要 `requests`，确认已安装 |
| SSH 连接失败 | 检查目标 22 端口是否开放、密码是否正确 |
| 报告评分全是 100 分 | 目标可能没有可发现的漏洞，换一个有漏洞的测试目标 |
| 交互菜单选了没反应 | 检查是否缺少对应模块的依赖库 |
